---
title: "Очищення кешу"
openapi: "POST /v1/refresh/{id}"
---

Скидає закешовані результати пошуку джерел для конкретного фільму або серіалу та ініціює новий живий парсинг.

<Note>
**Обмеження (Cooldown):** Очищення кешу для конкретного медіа дозволено не раніше ніж через **2 години** після його останнього парсингу.
Якщо спробувати оновити джерела раніше, API поверне HTTP `429 Too Many Requests` із заголовком `Retry-After`.
</Note>
