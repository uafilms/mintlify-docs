## Отримання API-ключа

Для роботи з API та зняття обмежень гостьового режиму рекомендується використовувати персональний API-ключ.

1. Перейдіть до онлайн-кінотеатру **[films.aartzz.pp.ua](https://films.aartzz.pp.ua)**.
2. Створіть акаунт через форму входу (підтримуються поштові сервіси Gmail, Outlook, Proton, Ukr.net, iCloud).
3. Відкрийте **Налаштування** ➔ **Обліковий запис** ➔ кнопка **API** (або напряму [films.aartzz.pp.ua/dashboard](https://films.aartzz.pp.ua/dashboard)).
4. Натисніть **«Створити ключ»**, вкажіть зрозумілу назву (наприклад, `Мій бот` або `Мобільний клієнт`) і скопіюйте згенерований ключ (`uaf_live_...`).

<Warning>
  Повний ключ відображається **лише один раз** під час створення! Збережіть його у надійному місці.
</Warning>

## Способи передачі API-ключа

Ви можете авторизувати свої запити одним із трьох зручних способів:

### 1. HTTP-заголовок `x-api-key` (Рекомендовано)

```bash
curl -H "x-api-key: uaf_live_ваш_ключ" \
  https://films.aartzz.pp.ua/v1/movies/1423191
```

### 2. Заголовок `Authorization: Bearer`

```bash
curl -H "Authorization: Bearer uaf_live_ваш_ключ" \
  https://films.aartzz.pp.ua/v1/movies/1423191
```

### 3. GET-параметр у URL (зручно для плеєрів та стрімінгу)

```bash
curl "https://films.aartzz.pp.ua/v1/movies/1423191?api_key=uaf_live_ваш_ключ"
```

## Захист та Ліміти запитів

Сервер UAFilms використовує багаторівневий захист для запобігання зловживанням:

- **Авторизовані користувачі (з API-ключем):**
  - Не потребують проходження капчі Cloudflare Turnstile.
  - Отримують повну персональну аналітику в особистому кабінеті (графік викликів, середній час відповіді, журнал останніх 50 запитів).
  - Мають пріоритетну швидкість резолвінгу стрімів.

- **Гостьові/неавторизовані запити:**
  - На методи пошуку контенту та перегляду каталогу (`/api/home`, `/api/search`, `/api/details`) обмеження м'які.
  - На методи парсингу джерел (`/v1/movies/*`, `/v1/tv/*`) діє ліміт **10 запитів на хвилину** на одну IP-адресу.
  - За наявності захисту Cloudflare Turnstile неавторизовані запити повинні містити валідний токен у заголовку `cf-turnstile-response` або query-параметрі `turnstile_token`.

## Робота з OMSS (Server-Sent Events)

При парсингу стрімів фільмів чи серіалів деякі сайти-провайдери можуть відповідати за 300 мс, а інші за 2-3 секунди. Щоб плеєр не очікував усіх провайдерів, підтримується режим потокової передачі **SSE**:

```javascript
// Підключення до стріму знайдених джерел через EventSource
const eventSource = new EventSource(
  'https://films.aartzz.pp.ua/v1/movies/1423191?sse=1&api_key=uaf_live_ваш_ключ'
);

eventSource.addEventListener('provider', (event) => {
  const data = JSON.parse(event.data);
  console.log(`Отримано джерела від ${data.name}:`, data.sources);
});

eventSource.addEventListener('complete', (event) => {
  console.log('Пошук завершено для всіх провайдерів.');
  eventSource.close();
});
```
