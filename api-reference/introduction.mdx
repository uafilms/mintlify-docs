## Авторизація

Щоб парсити стріми, вам буде треба API-ключ. Щоб його отримати, перейдіть у телеграм-бота [@films_aartzz_bot](https://t.me/films_aartzz_bot)

### Передача ключа

Є декілька способів передати ключ:

**Варіант А: заголовок `x-api-key`.**

```http
GET /api/home HTTP/1.1
Host: bfilms.aartzz.pp.ua
x-api-key: YOUR_SECRET_KEY

```

**Варіант Б: GET-параметр**

```http
GET /api/home?token=0.xxxxxxx.xxxxxxx

```
