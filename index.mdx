## Що таке UAFilms?

UAFilms — це агрегатор фільмів та серіалів, який об'єднує контент з багатьох джерел (провайдерів) та надає зручний інтерфейс для пошуку та перегляду.

  <Card title="Мульти-провайдер" icon="server">

  </Card>
  <Card title="Торенти" icon="magnet">
    Вбудований пошук та парсинг торент-трекерів.
  </Card>
  <Card title="TMDB Інтеграція" icon="film">

  </Card>
  <Card title="Безпека" icon="shield-check">
    Захист API через Cloudflare Turnstile та систему API-ключів.
  </Card>
</CardGroup>
